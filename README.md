# Student Dropout Risk Analysis Dashboard

## Overview
This project analyzes student data to explore patterns associated with student dropout risk. It uses Python libraries for data analysis and visualization and Streamlit to create an interactive dashboard.

## Objectives
- Analyze student academic performance and attendance.
- Explore patterns associated with dropout status.
- Identify trends using statistical summaries and visualizations.
- Present findings through an interactive dashboard.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Streamlit

## Features
- Interactive dashboard for exploring student data.
- Filters for course type, study mode, semester range, dropout status, and attendance range.
- Visual analysis of attendance and academic performance.
- Summary statistics and charts.

## Dataset
The project uses a student dataset in CSV format. Ensure the dataset is available in the correct project folder before running the application. Do not publish private or sensitive student information.

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Install the required libraries:

   `pip install streamlit pandas numpy matplotlib seaborn`

4. Run the application:

   `streamlit run app.py`

   If your Python file has a different name, replace `app.py` with the actual filename.

5. Open the local URL shown in your terminal, usually `http://localhost:8501`.
